# Change Request-003: add statistical processing to OpenWebUI SRS Starter

Import operations provide a capability to collect performance and accuracy data sufficient to make a conclusion if the tested method is acceptable. However, it makes sense to introduce statistical tests for P95 response time similar to the compare_p95_to_threshold (...) procedure of [GitHub - vturovets/smart-comp](https://github.com/vturovets/smart-comp) project. It is also necessary to add a statistical test to compare the obtained accuracy figure to the specified threshold.

## Requirements

1. After each import operation in the Performance summary section, the user can observe: 
- P95 response time (already implemented), 

- P95 threshold value, 

- P95 inference along with confidence level. 

- Accuracy (already implemented),

- Accuracy threshold,

- Accuracy inference along with confidence level.
2. For P95 response time, filter out outliers, nulls, negative and non-numerical values, and apply the approach used in compare_p95_to_threshold (...) procedure of [GitHub - vturovets/smart-comp](https://github.com/vturovets/smart-comp) project. 

3. For Accuracy, apply the one-sample proportion test vs target:
   
   - Hypothesis:
     
     - H₀: `p = p₀` (e.g. 0.9 baseline)
     
     - H₁: `p < p₀` (one-sided – regression check)
   
   - Implementation: binomial test (exact) or normal approximation for large `n`.
   
   - If p-value < significance level → evidence that the accuracy dropped below the target. 

4. For the P95, the outliers threshold is set by P95_OUTLIERS_THRESHOLD variable, the default value is 10000 ms.

5. For both P95 and Accuracy the minimum sample size is configured in .env file by MIN_SAMPLE_SIZE variable. The default value is 1000.

6. For P95, the threshold value is defined by IMPORT_P95_THRESHOLD_MS (already implemented). The default value is 750 ms.

7. For Accuracy, the threshold value is defined by IMPORT_ACCURACY_THRESHOLD. The default value is 0.85.

8. The significance level is set by APLHA, the default value is 0.05.

9. For the P95, the allowed inference values are:  
   – *meets the target*  
   – *above the target*  
   – *insufficient data*

10. For the Accuracty, the allowed inference values are:  
    – *meets the target*  
    – *below the target*  
    – *insufficient data*

11. Add PyTest coverage to validate the correct implementation requirements 1- 10.
