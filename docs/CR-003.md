# Change Request-003: add statistical processing to OpenWebUI SRS Starter

Import operations provide a capability to collect performance and accuracy data sufficient to make a conclusion if the tested method is acceptable. However, it makes sense to introduce statistical tests for to compare both P95 response time and the obtained accuracy figure to the specified thresholds.

## Requirements

1. After each import operation in the Performance summary section, the user can observe: 
- P95 response time (already implemented), 

- P95 threshold value, 

- P95 inference along with confidence level. 

- Accuracy (already implemented),

- Accuracy threshold,

- Accuracy inference along with confidence level.
2. For P95 response time, filter out outliers, nulls, negative and non-numerical values, and apply the following approach: compare the empirical 95th percentile (P95) of the observed response-time distribution with a user-defined threshold IMPORT_P95_THRESHOLD_MS using bootstrap resampling. It generates a bootstrap distribution of the difference Δ=P95−IMPORT_P95_THRESHOLD_MS and computes a two-sided (1−APLHA) confidence interval CIΔ​=[Δlow​,Δhigh​]. If Δhigh​≤0, the inference is “*meet the target (1-APLHA)x100% CI )*”. If Δlow​>0, the inference is “*above the target (1-APLHA)x100% CI )*”. If the interval spans zero, i.e. Δlow​≤0<Δhigh​, the inference is “*insufficient data*” because the available sample does not allow a statistically confident conclusion at the specified confidence level.

3. For Accuracy, apply the one-sample proportion test vs target:
   
   - Hypothesis:
     
     - H₀: `p = IMPORT_ACCURACY_THRESHOLD` (e.g. 0.85 baseline)
     
     - H₁: `p < IMPORT_ACCURACY_THRESHOLD` (one-sided – regression check)
   
   - Implementation: binomial test (exact).
   
   - If p-value < significance level, the inference is "*below the target (1-APLHA)x100% CI*". Otherwise, “*meet the target (1-APLHA)x100% CI )*” if the number of observations is greater or equal MIN_SAMPLE_SIZE.

4. For the P95, the outliers threshold is set by P95_OUTLIERS_THRESHOLD variable, the default value is 10000 ms.

5. For both P95 and Accuracy the minimum sample size is configured in .env file by MIN_SAMPLE_SIZE variable. The default value is 1000. In the number of observations is less than MIN_SAMPLE_SIZE, the inferences for both P95 and Accuracy are "*insufficient data*".

6. For P95, the threshold value is defined by IMPORT_P95_THRESHOLD_MS (already implemented). The default value is 750 ms.

7. For Accuracy, the threshold value is defined by IMPORT_ACCURACY_THRESHOLD. The default value is 0.85.

8. The significance level is set by APLHA, the default value is 0.05.

9. Add PyTest coverage to validate the correct implementation requirements 1- 8.
